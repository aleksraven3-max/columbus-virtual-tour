# Віртуальний тур МКС — Модуль «Колумб» (Українська версія)

Українськомовна версія інтерактивного 360°-туру науковим модулем **Columbus** Європейського космічного агентства (ESA).

## 🚀 Що перекладено:
- Назви наукових стійок та лабораторій (Biolab, FSL, EDR, EPM тощо).
- Текстові підказки, інструкції управління та навігаційні кнопки («Закрити», «Відкрити на весь екран»).
- Опис модуля та інтерфейсні панелі.

## 📌 Як розгорнути на GitHub Pages:
1. Завантажте всі файли з цього репозиторію у свій GitHub-репозиторій.
2. У **Settings -> Pages** оберіть гілку `main` і збережіть.
3. Отримане посилання вставте у **Google Sites** через блок **Вставити (Embed) -> За URL-адресою**.
