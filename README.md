# Віртуальний тур МКС — Модуль «Колумб» (Українська версія)

Оновлений проєкт 360-градусного туру науковим модулем **Columbus** на МКС із повністю українськомовними підказками та інтерактивними маркерами.

## 📁 Вміст проєкту:
- `index.html` — автономна версія туру на рушії Pannellum. Підказки з'являються українською мовою прямо на панорамі при наведенні/кліку на маркери.
- `USOS.xml` — файл конфігурації з українськими підказками (для оригінального плеєра Pano2VR).
- `.gitignore` — налаштування ігнорування системних файлів.

## 🚀 Як оновити на GitHub Pages:
1. Завантажте цей zip-архів та розархівуйте його.
2. Перейдіть у свій репозиторій на GitHub (`columbus-virtual-tour`).
3. Замініть файл `index.html` та додайте `USOS.xml`.
4. Збережіть зміни (**Commit changes**).
5. Зачекайте 1 хвилину — ваш сайт `https://aleksraven3-max.github.io/columbus-virtual-tour/` оновиться і покаже тур із перекладеними підказками!
