# Віртуальний тур МКС (Модуль «Колумб»)

Інтерактивний 360°-тур науковим модулем **Columbus** на Міжнародній космічній станції (ESA).

## 🚀 Проєкт
Цей проєкт налаштовано для швидкої інтеграції та розміщення на **GitHub Pages** або вбудовування через `iframe` у навчальні платформи (наприклад, Google Sites).

## 📌 Як використовувати
1. Запустіть проєкт через GitHub Pages.
2. Вставте посилання у Google Sites через модуль **Вставити (Embed) -> За URL-адресою**.

---
*Оригінальні матеріали належать Європейському космічному агентству (ESA).*
