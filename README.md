# Віртуальний тур МКС 1.0 — українська версія

Неофіційний український переклад підписів інтерактивного 360° туру Міжнародною космічною станцією
від Європейського космічного агентства (ESA). Тур складається з 8 модулів:
Columbus, Kibo, Harmony (Node 2), Destiny, Unity (Node 1), Tranquility (Node 3), Zarya (Зоря), Zvezda (Зірка).

Оригінал: <https://esamultimedia.esa.int/multimedia/virtual-tour-iss/>

## Що в цьому репозиторії

| Файл | Призначення |
|---|---|
| `index.html` | Сторінка туру (написи «Закрити» / «На весь екран» українською, посилання переведені на HTTPS) |
| `ISS1.0_uk.xml` | Конфігурація туру з перекладеними підписами |
| `.nojekyll` | Вимикає обробку Jekyll на GitHub Pages |

## Чого тут немає і що потрібно додати

Зображення панорам, плеєр і оформлення належать ESA, тому вони **не входять** до цього репозиторію.
Щоб тур запрацював, скопіюйте з оригінального туру в корінь репозиторію:

- `pano2vr_player.js`
- `skin.js` (і, за потреби, `skin.xml`, `pano2vr_player.swf`)
- `swfobject.js`
- папку `tiles/` з усіма зображеннями панорам
- зображення інтерфейсу, на які посилається `skin.js` (їх видно у вкладці Network браузера, `F12`)

Структура має бути такою:

```
index.html
ISS1.0_uk.xml
pano2vr_player.js
skin.js
swfobject.js
tiles/
  Columbus_18_sRGB MASTER/...
  Kibo Panorama/...
  Node2 Panorama/...
  Lab Panorama/...
  Node 1 Panorama brighter/...
  node3_10_7_sRGB_leveled brigther/...
  FBG_Panorama-6-9_sRGB_tonemapped/...
  Zvezda-SM Panorama3_0/...
```

Перш ніж публікувати чужі матеріали, перевірте умови використання контенту ESA
(розділ про авторські права на сайті esa.int) і за потреби отримайте дозвіл.

## Локальний запуск

```bash
python3 -m http.server 8000
```

Потім відкрийте <http://localhost:8000>. Відкривати `index.html` подвійним кліком не варто:
браузер не завантажує XML із файлової системи.

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте всі файли.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Через хвилину-дві тур буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Що лишається англійською

- відео (воно завантажується з сервера ESA і озвучене англійською);
- статті, на які ведуть текстові іконки (ESA, NASA, JAXA);
- можливі написи інтерфейсу всередині `skin.js`.
